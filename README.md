# Webflow Comment Filter

A Chrome extension built with **Spiderflow** to make feedback easier to find in Webflow Designer.

## The problem

Large Webflow projects can accumulate many comments. Finding feedback from a particular reviewer or time period can interrupt the development workflow.

## Features

- Filter comments by author.
- Filter comments by when they were posted.
- Search comment text.
